# Jeel Kotadiya — Frontend Portfolio

Built with plain HTML, CSS, and JavaScript (no React or other framework).

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in your browser.

## Before publishing
- Replace the example email and generic GitHub/LinkedIn links with your real links.
- Add your resume as `resume.pdf` in this folder for the Download Resume link to work.
- Update project links and descriptions with your actual projects.
- The contact form validates fields in the browser only. To receive messages, connect a backend or a form service.
